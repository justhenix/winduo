# WinDuo
Slight iPhone Duo / Mac-style desktop blur for a normal Windows laptop.
Native C++ / Win32.

Most Windows laptops do not have a lid-angle sensor. MacBooks do. WinDuo cannot track your hand on the hinge.

## What actually works
- Ctrl+Alt+Space or tray click — close / open the virtual hinge
- Lid open / closed — ease blur on / off
- Experimental (cursed) webcam hinge — off by default. Uses the lid camera because there is no angle chip. LED on = camera on. Frames stay in RAM. Nothing is uploaded.

Tray accessory. MIT. No accounts.
